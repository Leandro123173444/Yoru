# Contribuir a YORU

1. Hacé un fork y creá una rama para tu cambio.
2. Compilá con `./gradlew :app:assembleDebug` (JDK 21, Android SDK 36, NDK 27.0.12077973).
3. Abrí un pull request explicando el problema y el comportamiento resultante.

Al contribuir aceptás que tu aporte se publique bajo la licencia Apache 2.0 del proyecto.
